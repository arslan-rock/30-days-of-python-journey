## 🚀 About the Challenge

The **30 Days of Python** challenge is a structured learning program designed to help beginners learn Python step by step through daily lessons, exercises, and projects.

The challenge covers:

* Python fundamentals
* Data types and variables
* Operators and expressions
* Strings and string manipulation
* Collections and data structures
* Control flow and problem-solving
* Functions, modules, and more

The goal is to develop practical programming skills through consistent daily practice.

## 💻 How to Run the Code Locally

### 1. Clone the repository

```bash
git clone https://github.com/arslan-rock/30-days-of-python-journey.git
```

### 2. Navigate to the project directory

```bash
cd 30-days-of-python-journey
```

### 3. Run any Python file

```bash
python filename.py
```

Or:

```bash
python3 filename.py
```

Make sure Python is installed on your system.
